# Apostilas da Carreira Dados

Apostilas das trilhas da mentoria Carreira Dados ([carreiradados.com.br](https://carreiradados.com.br)).
Cada trilha tem uma pasta, com uma apostila por módulo, laboratórios e referências.

Mantido por Iuri Zambotto e Paulo Shindi.

## Trilhas

| Pasta | Trilha | Estado |
|---|---|---|
| `engenharia_de_dados/` | Engenharia de Dados | 12 módulos com texto, 9 publicados e 3 em rascunho; ordem sugerida em `engenharia_de_dados/README.md` |

## Como usar

Cada módulo tem `README.md` e `apostila.md` em `<trilha>/modulos/<módulo>/`. Os módulos com
laboratório trazem `lab.json` e a pasta `infrastructure/`, com os passos para rodar na sua máquina.

A ordem dos módulos é sugestão, não obrigação de percurso: cada mentorado tem um roteiro próprio.

## Origem

A trilha de Engenharia de Dados veio do repositório `carreiradadosia/mentorias` em 2026-10-29,
com o histórico de commits preservado.
